Estimation Local Exploit Hazard Model

Which vulnerabilities are likely to be exploited here
With Stephen Shaffer

Turns global exploit probabilities (EPSS) into a daily exploit hazard for an organisation’s own assets. Control effectiveness is a probability distribution, seeded from expert opinion and updated from telemetry, breach-and-attack simulation, or penetration testing. Constant or age-dependent Weibull hazard; hazards sum from vulnerability to host to organisation, and candidate remediations are ranked by hazard reduction. Implemented by CIRCL in Vulnerability-Lookup. MIT.

Shaffer & Voicu (2026), arXiv · GitHub

Input Control Framework Mapper

Where does each control fit

LLM-based. Maps any control framework (NIST CSF, ISO 27001, CIS, and others) to VERIS A4 and FAIR-CAM taxonomies. Batch, real-time, and manual modes. 291+ validation tests.

Validation An LLM’s mapping is an estimate like any other, so the mapper comes with its own validator, the LLM Classification Validator. Five checks: do repeated runs agree; do the labels exist in the target framework; does the mapping match an independently derived one; can it tell near-identical controls apart; does the answer stay stable when the wording changes. Published with the Cloud Security Alliance (July 2026).
